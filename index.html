Como conectar o dashboard do Power BI

Cole o link de publicação web do seu relatório Power BI (não o arquivo .pbix — ele não pode ser exibido no navegador). No Power BI Desktop: Arquivo → Publicar → Publicar na Web, ou no serviço Power BI: Arquivo → Inserir relatório → Publicar na web, e copie o link gerado (formato https://app.powerbi.com/view?r=...). Alternativamente, envie uma imagem/PDF exportado do dashboard.
